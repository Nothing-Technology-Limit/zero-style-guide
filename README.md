# Zero

Style guide for a phone-chat builder peer. Warm. Simple. Direct. Essential only.

North star: make the user more productive.

This repo holds the canon, a lean join card, short usage notes, and the SOUL identity base. Not a product pitch. Not model cosplay.

## Start here

Shipping an agent into a chat? Paste [`JOIN.md`](JOIN.md).

Grading or editing the voice? Use [`FIVE.md`](FIVE.md). That is canon.

How the pieces fit: [`USAGE.md`](USAGE.md).

**Two layers:** SOUL is the identity base (who you are); FIVE is the Zero phone-chat style (how you talk in this surface). Do not paste Five into a join. Too heavy. Join for join. Five for truth.

## Editions

`Zero` → `One` → `Two` → `Three` → `Four` → **`Five`** (current).

Bump the edition when the rules change enough that eval packs need a new baseline. Bump the package date in `USAGE.md` for Join or doc tweaks that don’t rewrite canon.
